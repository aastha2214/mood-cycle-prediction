# Candidates for a second, independent dataset (research only; nothing was downloaded)

*Search date: 2026-11-24. Method: about ten web searches with the search tool and eight public pages read through a web-fetch helper (read only; no login, no registration, no data file downloaded, nothing uploaded). Limits: this is not an exhaustive repository search; a dataset that I did not find may exist. "Verified" = I read the page text; "reported" = taken from a search summary or from a paper that cites the dataset and not yet checked at the source. Terminology: using one of these would be **cross-dataset validation** only if it is a truly separate study; E7 in the report is cross-sample validation inside the present study.*

## Short answer
**No fully open dataset with compatible variables (several women, menstrual cycle phase or salivary estradiol/progesterone, plus a mood or symptom score) was found.** Nothing can be used immediately for that purpose. The closest items are either restricted (mcPHASES), contain only one woman or four participants (28andMe, NeuroCycle), contain hormone and cycle-phase data but no mood outcome (the OSF collation of the "spitting distance" paper), or are published studies whose data availability could not be established (Doornweerd and Gerritsen 2025; Hahn et al. 2020; BMC Women's Health 2024 studies). I will not use any of them without your approval.

## What this means for the paper
- A second independent dataset **with compatible variables is not available to me right now**; the report therefore claims **cross-sample** validation (two disjoint groups of women of the same study), not cross-dataset validation.
- **Possible next steps that need your decision (I will not do them on my own):** (a) ask the authors of #5 and #6 or the BMC studies in #7 whether data can be shared; (b) if you want to use mcPHASES (#1), you would have to register and sign the data use agreement yourself, and its variables differ (urinary hormones, wearable data), so it would need a separate, clearly labelled analysis; (c) check the OSF folders of #3 (hormone and cycle-phase data only) if a hormone-versus-phase validation (not mood) would be useful, after confirming the licence with the authors.
- **Not done, deliberately:** no download of any file, no registration, no upload of project data anywhere.
